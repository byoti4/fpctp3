## 🌟 核心特色與功能

1. **學術級分析架構**：
   每一頁皆嚴格遵循「**策略理論 (Theory) ➔ 實證數據 (Evidence) ➔ 團隊分析結論 (Insight)**」三層結構，解析企業國際化路徑，非單純公司簡介。
2. **六大核心分析主題 (Themes)**：
   * **主題 1：垂直整合** - 集團內部化交易流程與 OLI 優勢（約 62% 原料來自台塑化 6505）。
   * **主題 2：水平分工** - 麥寮六輕基礎設施（發電、管線、碼頭）共享與四寶群聚效應。
   * **主題 3：全球擴張** - 台灣（技術合資）、美國（資源併購與綠地）、中國寧波（市場複製）的 FDI 策略權衡。
   * **主題 4：跨國併購** - 台塑 1980 年代至今「用資本換時間」的併購演進三階段。
   * **主題 5：綠地與聯盟** - 進入模式選擇決策樹（核心石化高控制 vs 跨界合資分擔風險）。
   * **主題 6：轉型挑戰與建議** - 面臨碳費、能源轉型與 2024 年首次虧損之應對策略與集中多角化建議。
3. **語音導覽與動態聲波**：
   * 內建語音朗讀功能，自動朗讀當前主題及圖表點選節點之詳細策略解析。
   * 可收闔式右側面板，收闔後縮小為貼合螢幕右邊緣的精緻懸浮標籤，並於播放中動態啟用 CSS 等化器聲波震動動畫。
4. **多國語言支持 (I18N)**：
   * 支援中文 (`zh`) 與英文 (`en`) 動態無縫切換，包含 UI、分析內容與語音朗讀口播字串。
5. **Mistral AI 極致設計美學**：
   * 嚴格對齊 `DESIGN.md` 規範，採用溫暖的日落漸層（ mustard, orange, deep red ）、溫潤的奶油黃背景 (`--cream`) 與橘色主按鈕顏色。
   * 支援高對比度的深色模式（Dark Mode），修正深色底下的文字對比度，所有按鈕與徽章完美適配。
6. **標準 RWD 五大斷點優化**：
   * 桌機、平板與手機等不同尺寸下皆能流暢缩放與折疊網格，行動端提供流暢的側邊收闔導覽與漢堡選單。

## 🚀 如何運行與測試

本專案為無編譯步驟的純前端靜態網頁，極易部署與運行：

### 方法 A：直接開啟（本機瀏覽）
雙擊本機目錄底下的 `index.html` 檔案即可在 Chrome、Edge 或 Safari 等現代瀏覽器中直接運行完整功能。

### 方法 B：使用本機伺服器（推薦，體驗最佳）
為了確保語音引擎、本機儲存（localStorage）與部分瀏覽器 API 能在最標準的安全上下文中執行，建議透過輕量級本機伺服器開啟。
1. **使用 Python** (如果已安裝 Python)：
   ```bash
   python -m http.server 8000
   ```
   接著在瀏覽器中輸入 `http://localhost:8000` 即可。
2. **使用 Node.js (`live-server` 或 `npx`)**：
   ```bash
   npx live-server
   ```
   或使用 VS Code 的 `Live Server` 套件直接點擊 `Go Live` 運行。
